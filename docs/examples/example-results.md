# Example Results

These movies show a five-spot pump network. Four outer spots arrive first and prepare the reservoir; the delayed central probe is kept fixed in every run. With weak priming the center stays below condensation, while stronger priming lowers the effective threshold and the same probe produces a central spike.

Each movie shows the same three fields: condensate density `psi^2`, active reservoir `nA`, and inactive reservoir `nI`.
